In LocalAI

Install it in one line

Pull a model from the gallery, then call the OpenAI-style endpoints.
who said what
$ local-ai run parakeet-cpp-nemotron-3-diarization-asr
$ curl localhost:8080/v1/audio/diarization \
    -F file=@meeting.wav \
    -F model=parakeet-cpp-nemotron-3-diarization-asr \
    -F include_text=true
what else is in the audio
$ local-ai run parakeet-cpp-ced-base
$ curl localhost:8080/v1/audio/classification \
    -F file=@clip.wav -F model=parakeet-cpp-ced-base
